# Verification scope

Local checks cover TypeScript, reproducible prerender/build, Worker routing, consent storage exceptions, page metadata, visible FAQ/schema and resource references. Production deployment, actual browser layout, menu operation and image loading require a separate final check; a local build alone does not establish those results.

Reconfirm current entry conditions, upper-level access, lift operation, fees, facilities and transport before adding operational claims. Preserve the photo source/licence links and the unresolved Commons nomination note.
